# Motor Controller Framework v3 Doxygen Pack

This pack contains Doxygen pages, Graphviz diagrams, C headers and minimal source stubs for the STM32G474RET3 motor-controller framework. It is intended as a starting point for AI-assisted C firmware generation.

Build docs with:

```bash
doxygen Doxyfile
```

The CubeMX-generated STM32 project should include the `include` path and compile sources from `src` plus target-specific wrapper files added later.
